HOTLINE MIAMI: REDUX-REDUX — КООПЕРАТИВ ДО 4 ИГРОКОВ
====================================================
Версия 2.2.2

Это фанатский мод Hotline Miami: Redux-Redux с добавленным сетевым кооперативом
(до 4 игроков). Один игрок — ХОСТ (создаёт игру, вся логика уровня считается у
него), остальные — КЛИЕНТЫ (подключаются к хосту по IP).

ВАЖНО: у всех игроков должна быть ОДНА И ТА ЖЕ версия этой папки. Если версии
разные, лобби откажет в подключении («версия»). Версия 2.2.2 соединяется с 2.2,
2.2.1 и 2.2.2 (тот же протокол), но лучше обновитесь все.

1. КАК ЗАПУСТИТЬ ИГРУ
---------------------
1) Распакуйте архив в любую папку (например, на рабочий стол). Путь лучше без
   особых символов.
2) Запустите «Hotline Miami Redux Redux.exe».
3) Дождитесь главного меню игры.

Python, UndertaleModTool и прочие программы НЕ нужны — всё уже собрано.

При первом запуске Windows может спросить разрешение для сети (брандмауэр).
Разрешите доступ (частные сети, а для игры через интернет — и общественные),
иначе к хосту не подключиться.

Сохранения игра хранит в %APPDATA%\Hotline_Miami_Redux_Redux (как обычная
Redux-Redux).


2. КАК ОТКРЫТЬ ЛОББИ И ПОДКЛЮЧИТЬСЯ
-----------------------------------
Лобби открывается клавишей F8 в ГЛАВНОМ МЕНЮ игры.

ХОСТ (создаёт игру):
1) В главном меню нажмите F8.
2) Введите свой ник (поле NICK).
3) Нажмите CREATE GAME. Вы — игрок P1.
4) Сообщите друзьям свой IP-адрес (см. раздел 3).
5) Когда все подключились и нажали READY, нажмите START.
6) Начните игру как обычно (NEW GAME / CONTINUE) — клиенты переходят в уровни
   вслед за хостом автоматически.

КЛИЕНТ (подключается):
1) В главном меню нажмите F8.
2) Введите свой ник (поле NICK).
3) В поле HOST IP введите IP-адрес хоста (например, 26.12.34.56). Удобнее
   скопировать адрес (из Radmin VPN или мессенджера) и нажать PASTE IP
   (или щёлкнуть по полю и нажать Ctrl+V).
   Поле PORT не трогайте (47800), если хост не говорил другого.
4) Нажмите JOIN GAME.
5) При желании выберите свободный слот (P2–P4) и нажмите READY.
6) Ждите, пока хост нажмёт START.

Выход из лобби — кнопка LEAVE. Если хост вышел, у клиента появится надпись
«HOST LEFT THE GAME».


3. ИГРА ЧЕРЕЗ ИНТЕРНЕТ (RADMIN VPN / ZEROTIER)
---------------------------------------------
Для игры через интернет скачайте Radmin VPN (или ZeroTier), создайте сеть, и
используйте выданный IP-адрес (обычно 26.x.x.x) для подключения.

Подробнее (Radmin VPN):
1) Все игроки скачивают Radmin VPN с официального сайта (radmin-vpn.com) и
   устанавливают его.
2) Хост в Radmin VPN: «Сеть» -> «Создать сеть», придумывает имя и пароль.
3) Остальные: «Сеть» -> «Присоединиться к сети», вводят то же имя и пароль.
4) Хост смотрит СВОЙ адрес в окне Radmin VPN (вверху, рядом с именем
   компьютера, обычно вида 26.x.x.x) и сообщает его друзьям.
5) Клиенты вводят этот адрес в поле HOST IP в лобби (раздел 2).

ZeroTier работает так же: хост создаёт сеть на my.zerotier.com, все входят в неё
по ID сети, а для подключения используется адрес хоста из этой сети.

В одной домашней сети (Wi-Fi/LAN) VPN не нужен: используйте локальный адрес
хоста (обычно 192.168.x.x, его показывает команда ipconfig).

Если не подключается:
- проверьте, что брандмауэр Windows у хоста разрешил игру (UDP-порт 47800);
- проверьте, что все в одной сети Radmin/ZeroTier и адрес введён правильно;
- у всех должна быть одна и та же версия этой папки.


4. ГОРЯЧИЕ КЛАВИШИ
------------------
F8     — открыть/закрыть лобби (в главном меню).
F9     — сетевой оверлей: состояние соединения, пинг, игроки, отладочные данные.
TAB    — (держать) таблица игроков: персонаж, враги, казни, падения, пинг.
F5     — сплит-скрин: экран делится на виды всех игроков (1–4). Это режим
         ЛОКАЛЬНОЙ ОТЛАДКИ: работает, только если игра запущена файлом
         «Отладка (F5 сплит).bat». В обычной игре у каждого свой полный экран.

В игре (как в оригинале):
WASD   — движение;  мышь — прицел;
ЛКМ    — атака / выстрел;
ПКМ    — подобрать / бросить оружие;
Space  — казнить лежащего врага (встаньте над ним; удары — ЛКМ);
E      — поднять упавшего союзника (подойдите и держите E 2 секунды).

Если вы упали (DOWNED): союзник может поднять вас за 5 секунд, иначе вы погибаете.
Когда вы мертвы (режим наблюдателя):
Q / E  — переключение между живыми союзниками;
Space  — свободная камера / следить за союзником;
WASD   — двигать свободную камеру.
Если живых игроков не осталось — уровень перезапускается через 3 секунды.


5. ОТЛАДКА
----------
«Отладка (F5 сплит).bat» запускает игру с ключом -coop_debug: включается F5
(сплит-скрин) и отладочные клавиши хоста для проверки (F3, F6, F7, F10, F11, F12 —
создают врагов, оружие и выстрелы). Для обычной игры запускайте .exe напрямую.
